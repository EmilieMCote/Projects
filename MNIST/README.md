# MNIST Project

This folder contains a set of Jupyter notebooks that explore the MNIST handwritten digit dataset using a variety of machine learning and deep learning techniques.

## Notebooks

### `MNIST_with_Keras.ipynb`
- Introduces deep neural networks (DNNs) using Keras.
- Steps through the full DNN workflow:
  1. Load and preprocess MNIST data.
  2. Define the neural network architecture.
  3. Choose the optimizer and cost function.
  4. Train the model.
  5. Evaluate performance on unseen test data.
  6. Perform hyperparameter tuning to improve model performance.

### `SoftMax_LogisticRegression_MNIST.ipynb`
- Covers logistic regression and Softmax regression for multi-class classification.
- Demonstrates regularization and solver choices for MNIST.
- Trains models on the digit dataset and evaluates classification performance.
- Visualizes learned weight maps and decision behavior for regression-based models.

### `PCA_with_MNIST.ipynb`
- Applies Principal Component Analysis (PCA) to MNIST for dimensionality reduction.
- Shows how PCA transforms the 784-dimensional digit images into a smaller feature space.
- Uses the reduced representation in modeling and classification.
- Explains PCA theory and how it captures the most important directions of variance.

### `Clustering.ipynb`
- Demonstrates unsupervised learning with MNIST.
- Uses dimensionality reduction and clustering methods to group digit images.
- Focuses on UMAP-based embedding and cluster analysis.
- Visualizes how MNIST digit classes separate in lower-dimensional space.

## Files

- `mnistX.dat` and `mnistY.dat`: data files used by the project.
- `Part4_data.dat`: additional dataset used within the MNIST workflows.
- `imgs/`: plots and visualizations generated by the notebooks.

## Usage

Open the notebooks in Jupyter or VS Code to run the code cells and explore the results.

> Note: Some data files are large; if you plan to share this repository widely, consider using Git LFS for the larger dataset files.
